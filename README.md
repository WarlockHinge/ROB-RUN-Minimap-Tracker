# ROB RUN Minimap Tracker

Download: soon

Minimap tracker with player dots, arrows, ring distances and a widget that stays where you leave it.

## Widget

| Setting | Default | Range |
| --- | --- | --- |
| scale | 95% | 55-140 |
| opacity | 75% | 20-100 |
| range | 480 m | 150-800 |
| rings | 100 m | 50-200 |
| corner snap | off | on/off |

## Reading

You are the centre dot, arrows show movement, ring gap is the chosen distance. Cold colors mean the target is behind geometry.

## Install

1. Extract, admin loader, start ROB RUN
2. INSERT, F9 shows the widget
3. Drag into a map corner, lower scale until it stops covering the compass

## Troubleshooting

Widget resets: exit via menu so the profile saves. Dots lag: refresh interval raised by the profiler, restart the loader.

Radar survives patches longer than aim modules, EAC still breaks it eventually.

Windows 10/11, Steam.
